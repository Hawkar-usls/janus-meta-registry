# EYE — Primary JANUS Registry Integration Root

`EYE/` is the primary integration workspace of `janus-meta-registry` for EYE + TRUMP + SLIME.

It **does not move, replace, or rewrite** the canonical source artifacts already living under `data/`, `registry/`, `docs/`, or other historical paths. Instead, EYE learns a rebuildable derivative view of the entire repository while preserving provenance.

## Canonical operator

```text
SOURCE
  -> REPRESENTATION CONTRACT
  -> PROVENANCE / RELATION GRAPH
  -> SLIME RETRIEVE + RANK
  -> TRUMP ROUTE / ADMISSION
  -> EYE BRIDGE EXTRACTION
  -> BOUNDED CANDIDATE OR SEMANTIC REGION
  -> INDEPENDENT VERIFY
  -> EXACT_MATCH | EXACT_MISMATCH | SEMANTIC_REGION_SUPPORTED | AMBIGUOUS | OPEN | BLOCKED
```

Short seal:

> EYE SEES THE BRIDGES. TRUMP CHOOSES THE LANE. SLIME REMEMBERS THE PATH. VERIFICATION DECIDES WHAT MAY BE SAID.

## What “training on the registry” means

The official trainer `EYE/training/train_eye_registry.py` scans the repository snapshot deterministically. It hashes every included file, parses supported text/JSON where bounded and safe, constructs explicit provenance/relation edges, derives contextual bridge tokens, builds a non-authoritative SLIME associative plane, and derives a TRUMP advisory routing index.

This is **corpus ingestion/index/graph learning**, not LLM or foundation-model weight training.

Generated state lives only under `EYE/generated/` and is excluded from its own source corpus so the index cannot recursively train on itself.

## Bound organs

- **EYE** — `data/JANUS-EYE-CONTEXTUAL-SEMANTIC-RECOVERY-METHOD-2026-09-01-v1.0.json`.
- **Representation Contract** — `data/JANUS-REPRESENTATION-CONTRACT-v1.0.json`.
- **SLIME** — `JANUS_ACTIVATOR_SLIME_MEMORY_R0`, the actual runtime candidate that passed the frozen Gold-vs-Ideal Activator route-memory benchmark; advisory only.
- **TRUMP** — receipt-grounded R6.3 M2R + regret-guard governance pattern, transferred to EYE as routing discipline only; its SAT-specific performance claims are not generalized into semantic truth.
- **VERIFY** — remains independent and retains terminal authority.

## Hard firewalls

```text
EYE != SHA256_REVERSAL
SEMANTIC_REGION != EXACT_PLAINTEXT
SLIME_ASSOCIATION != EVIDENCE
TRUMP_ADMISSION != TRUTH
UNKNOWN != NEGATIVE
RESOURCE_LIMIT != TARGET_NEGATIVE
GENERATED_INDEX != SOURCE_AUTHORITY
CONTROL MUST HAVE POWER TO SAY NO
```

The entire point of this root is to make JANUS better at finding bridges **without becoming more willing to invent them**.
