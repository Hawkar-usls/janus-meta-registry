# Portfolio status — JANUS Meta Registry

The JANUS Meta Registry is an **archival knowledge/research notebook and provenance store**, not a flagship scientific result.

It contains historical hypotheses, metaphors, red-team artifacts, creative reversals, abandoned routes, speculative labels, safety boundaries, and later corrections. File names and historical terms are preserved for lineage and reproducibility; they must not be read as current empirical claims.

In particular, historical labels containing words such as `tachyon`, `precognitive`, theological language, or P/NP speculation are **names of archived hypotheses / experiments / metaphors unless a specific object explicitly establishes a narrower result under stated evidence gates**.

```text
PROJECT_CLASS = ARCHIVAL_META_REGISTRY
FLAGSHIP_RESEARCH = FALSE
HISTORICAL_SPECULATION_PRESERVED = TRUE
METAPHOR_AS_PHYSICS = FORBIDDEN
PRECOGNITION_CLAIM = NOT_ESTABLISHED
PHYSICAL_RETROCAUSALITY = NOT_ESTABLISHED
P_VS_NP_RESOLUTION = NOT_ESTABLISHED
```
