## Status

**Archival.** This repository preserves historical hypotheses, experiment records, structured artifacts, red-team results, corrections, provenance, personal/symbolic material, and technical snapshots.

It is **not one scientific theory** and **not a flagship research result**. Different archived objects carry different evidence classes.

## Reading rules

```text
MATURITY = ARCHIVAL
ARCHIVED_NAME != CURRENT_CLAIM
HYPOTHESIS != RESULT
METAPHOR != PHYSICS
CORRELATION != CAUSATION
PREREGISTRATION != POSITIVE_RESULT
INTERNAL_REPLICATION != INDEPENDENT_REPLICATION
CI_PASS != PEER_REVIEW
HASH_OR_SIGNATURE != TRUTH_OF_CONTENT
PROOF_IN_FILENAME != UNIVERSAL_PROOF_STATUS
```

Historical filenames containing terms such as `tachyon`, `precognitive`, `time traveler`, `God`, `Holy Clock`, `P=NP`, alchemy, or other project vocabulary remain unchanged for provenance. Their names do not establish the literal proposition suggested by the label.

## What registry presence does not establish

- prophecy, precognition, telepathy, or physical retrocausality;
- P vs NP resolution;
- medical efficacy, diagnosis, or clinical authority;
- machine consciousness, sentience, organismhood, or divine status;
- world novelty or historical priority without external review;
- a safe laboratory procedure;
- causation from correlation;
- a security vulnerability merely because a preregistration or unusual timing observation exists.

## Preservation policy

```text
proposal
→ evidence gate
→ test / red-team
→ result / null / obstruction / unresolved
→ correction / supersession
→ preserved lineage
```

Historical objects are not silently rewritten to match later conclusions. A newer audit/status layer governs current interpretation while the earlier object remains available for provenance.
