# SET signal — ORDER FROM CHAOS

This directory is the registry destination for the deterministic image-line transforms referenced by `JANUS-SET-ORDER-FROM-CHAOS-MULTIPASS-LAMBDA-MESSAGE-2026-08-16-v1.0`.

The transform is implemented in `research/set_signal/set_order_from_chaos_r2.py` and is derived from the earlier `data/Angel.json` image-to-ordered-line experiment.

Stages: `CHAOS -> ORDER_1 -> ORDER_2 -> ORDER_LOCK`.

The source posters were supplied in the ChatGPT conversation. The session produced the following render names:

- `SET_MESSAGE_PLATE_CHAOS_TO_ORDER_R2.png`
- `SET_MESSAGE_PLATE_ORDER_LOCK_R2.png`
- `LOST_RELIC_POSTER_CHAOS_TO_ORDER_R2.png`
- `LOST_RELIC_POSTER_ORDER_LOCK_R2.png`

The raster outputs are not duplicated here because this registry commit contains the deterministic algorithm and message artifact, while the conversation remains the source-image/render receipt. The filenames above are reserved as the canonical render names if the binaries are later admitted.

The transformation is algorithmic image processing, not a new generative image pass: grayscale/contrast normalization -> edge extraction -> luminous-symbol reinforcement -> contours -> simplified polylines -> deterministic structural ordering.
