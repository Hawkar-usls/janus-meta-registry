# Беккер, TMT и контекст ALI в JANUS

Канонический объект: [`JANUS-BECKER-TERROR-MANAGEMENT-ONTOLOGY-2026-10-18-v1.0.json`](../data/JANUS-BECKER-TERROR-MANAGEMENT-ONTOLOGY-2026-10-18-v1.0.json).
Машинный вход: [`BECKER_TMT_CURRENT.json`](../registry/psychology/BECKER_TMT_CURRENT.json).

JSON содержит 58 понятий с английскими идентификаторами/названиями и русскими определениями, 19 источников, 31 типизированную связь, 8 карточек научных свидетельств, 18 карточек контекста видео с таймкодами, 16 инженерных правил, 6 протоколов будущих синтетических испытаний, ограничения вывода и карту интеграций.

## Что именно прочитано

Два скриншота просмотрены непосредственно. Первый содержит обложку книги, второй — страницу о TMT. Полного текста русского издания нет: переводчик, ISBN и номера его страниц не выдуманы. Для расширения использованы издательские материалы, разрешённый ограниченный просмотр книги, материалы фонда Беккера и первичные записи психологических исследований. Предисловие Сэма Кина обозначено как предисловие другого автора.

Дополнительное видео пользователя — [ALI, «Почему существует Вселенная»](https://www.youtube.com/watch?v=85And7lYKI4). Получены исходные метаданные YouTube и прочитаны 1 727 сегментов автоматических русских субтитров. Текущая оригинальная версия длится 3 723 секунды. У сторонних копий другая длительность и смещённые таймкоды. Привязка в JSON приблизительная, по разделам. Визуальное содержание и дословная точность ASR не сертифицированы. Полные субтитры, аудио и изображения в Git не публикуются.

## Уровни знания

| Слой | Назначение | Предел |
| --- | --- | --- |
| `BECKER` | Исторические философские и психоаналитические понятия | Не универсальный причинный закон и не клинический инструмент |
| `TMT` | Конструкты более поздней исследовательской программы | Вывод ограничен исходом и протоколом |
| `METHOD` | Репликация, контроль, предрегистрация, независимость | Процедура сама не делает результат положительным |
| `VIDEO` | Атрибутированный контекст ALI | Пересказ автора не становится проверенной физикой |
| `JANUS` | Собственные инженерные решения | Аналогия не устанавливает человеческую психику у ИИ |

Many Labs 4 и его повторный анализ относятся к одному семейству данных. Провал выбранного эффекта защиты мировоззрения сохранён. Репликация 2025 года с N=3 447, 22 лабораториями и 11 странами относится к доступности мыслей о смерти; она не подтверждает автоматически защиту мировоззрения. Обзор Chen et al. 2025 описывает неоднородные результаты и противоречивые оценки публикационного смещения.

Из видео перенесены вопросы о конечности, объяснении, типах отсутствия, моделях, предпосылках и вычислительных ресурсах. Квантовое бессмертие, миры Платона, метафизическая воля и принцип плодовитости остаются атрибутированными обсуждениями. Никакие опасные процедуры из мысленного эксперимента не переносятся. Значение `null`, число `0`, `false` и отсутствие поля различаются исполняемой функцией `classify_absence`.

## Реальное подключение

В этом репозитории добавлены JSON Schema, проверка ссылок/хешей, локальный инструмент `tools/becker_tmt_review.py` и чистое ядро `tools/becker_tmt_policy.py`. Оно принимает строго типизированное предложение и возвращает маршрут проверки. Даже поле `verification_claimed=verified_artifact` — заявление вызывающего кода, а не независимый сертификат. Ни один вердикт не разрешает исполнение или научное повышение статуса.

В `Hawkar-usls/Janus_Genesis` та же проекция закреплена по SHA-256 и читается из пакета репозитория без сетевого запроса. Она включена в `safe_resident_snapshot`, попадает в фактический массив сообщений резидента и фиксируется в `becker_tmt_lens_delivery` его receipt. Сохранён SHA-256 точного массива сообщений. Тест использует явно обозначенного scripted provider; он проверяет доставку контекста, а не улучшение поведения LLM. Типизированный review доступен через `review_structured_proposal` и не является валидатором свободного текста резидента.

Отдельный discovery-мост включается в манифест канонической ветки `IO-Intellect-Observer`. HRaiN, iNaiHR, DemiHead, Swarm, Lapis и Cosmos перечислены с честным статусом контракта или ссылки: изменение всех их runtime не заявляется. Наличие файла не является ACK от Beetle, обновлением весов модели или подтверждением работы живого NAS.

## Проверка и применение

```bash
python -m pip install -r requirements-becker-tmt.txt
python tools/becker_tmt_review.py
python -m unittest discover -s tests -p test_becker_tmt_review.py -v
python tools/becker_tmt_review.py --proposal examples/becker_tmt_counterexample.json
```

Проверяющие процедуры запрещают стирать отрицательные свидетельства, получать полномочия из метафоры, сопротивляться остановке или превращать самоописание в диагноз. Исправление гипотезы по новому свидетельству направляется на внешнюю проверку. Значимость проекта и научный статус его утверждений остаются отдельными полями.

Следующий научный шаг — заранее замороженное сравнение baseline/lens на EX01–EX06 с одинаковыми моделями, инструментами и полными входами. Улучшение поведения моделей, теория сознания и личное бессмертие здесь не доказаны. P vs NP — `OPEN`.
