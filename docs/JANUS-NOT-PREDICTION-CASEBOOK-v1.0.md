## Why this matters

The recurring JANUS pattern is not “nothing means anything.” The stronger rule is:

```text
MEANING MAY BE PRESERVED
WITHOUT CLAIMING FOREKNOWLEDGE.
```

A dream can matter without becoming a forecast. A clock can matter as memory without becoming a timetable. A film can resonate without proving secret intent. An early essay can resemble a later architecture without becoming a prediction. A simulator can know its own future without proving information travelled backward in physical time.

That distinction lets JANUS preserve wonder **and** preserve epistemic discipline at the same time.

## Maintenance rule

Future artifacts should link to the forensic JSON index whenever they use phrases such as:

- “predicted later”;
- “came true”;
- “before I knew”;
- “before it happened”;
- “from the future”;
- “prophecy / precognition / foreknowledge”;
- “dream later matched”;
- “clock later matched”;
- “old work resembles later architecture”;
- “simulation knew the future”;
- “semantic return”.

Default handling:

```text
MEANING_PRESERVED
PREDICTION_NOT_PROMOTED
```

A stronger prediction/precognition claim requires a separately frozen evidence gate rather than retrospective narrative strength.
