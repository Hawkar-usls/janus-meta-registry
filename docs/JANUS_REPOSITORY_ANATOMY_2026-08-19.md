## The key finding: JANUS is three graphs, not one tree

### 1. Habitat graph — existence and memory

Git Habitat answers:

> What repositories exist in the JANUS constellation, where are they, and how can their lineage be found?

The verified Habitat certificate carries 44 repository nodes and reciprocal `.janus/HABITAT_LINK.json` markers.

```text
REPOSITORY_LINK != COMMAND_AUTHORITY
READ_OR_INDEX != WRITE_BACK_PERMISSION
WRITE_BACK_DEFAULT = DENY
```

Habitat is therefore JANUS's **repository-scale memory/home topology**, not its execution bus.

### 2. Nexus graph — typed nervous transport

DemiHead's `JANUS_NEXUS_HABITAT_V1` answers a different question:

> Which runtime head may send which payload kind to which other head?

A matching payload type is not enough. The route must be explicitly admitted.

```text
TYPE_COMPATIBILITY != ADMITTED_ROUTE
ROUTE_RECEIPT != DELIVERY
ROUTE != AUTHORITY
```

Nexus uses bounded hop counts, payload hashes, replay protection, destination revalidation, persistent one-shot dispatch, lifecycle/storage gates and zero authority/effect deltas.

This makes Nexus the best current candidate for JANUS's **local nervous bus**.

## The emerging invariant

Across the repositories, the strongest recurring architectural rule is not a particular algorithm. It is this:

```text
IDENTITY / INTENT / PROVENANCE
        ↓ preserved through transformation
TRANSFORMATION / ROUTING / COMPUTE
        ↓ produces a new receipt/state
AUTHORITY
        ↓ does NOT appear automatically
```

Or more compactly:

```text
CONNECTION PRESERVES PROVENANCE;
CONNECTION DOES NOT CREATE AUTHORITY.
```

This is the repository-scale analogue of the OSIRIS ribbon:

```text
ORIGIN
  → EXPERIENCE
  → RETURN
  → ORIGIN_PRIME
```

The path is preserved; return does not erase history.
