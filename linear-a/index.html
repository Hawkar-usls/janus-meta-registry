Linear A · corpus statistics · replication

Test structure first. Do not smuggle in a translation.

The JANUS Linear A program studies reproducible internal structure in Linear A corpora using frozen source versions, typed token representations, held-out evaluation, destructive null models, multiple implementations and explicit current-authority records.

Research pipelineCanonical stateExternal source intake

Typed representation

Punctuation, exact numeric values, approximate/uncertain numeric values and semantic candidates are separated before semantic scoring. Representation corrections remain part of the permanent lineage.

token typingparser auditdata provenance

Holdouts and replication gates

Screening, confirmation and non-HT replication are separated where the frozen design supports them. Unsupported regions are marked NOT_EVALUABLE instead of being silently treated as failures or successes.

holdoutregion replicationfail closed

Destructive nulls

Within-row shuffles, within-document identity shuffles, rewiring and family-wise error control are used to test whether candidate structure survives plausible corpus-preserving destruction.

permutation testsmax-TBonferroni

Multiple implementations

Different implementations are preserved and reconciled rather than silently selecting the one that produces the most interesting intermediate candidate.

What the pipeline has already caught

A historical structural survivor involving *900 was later identified as Aegean word-separator punctuation rather than a semantic token. The parser policy was corrected and the failed interpretation was preserved as an audit record instead of being erased.

This is exactly the kind of correction the registry is designed to retain.
