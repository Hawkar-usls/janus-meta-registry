# Claim boundary

The A18.44 seal proves only that a byte-identical hypothesis and experiment precommitment existed at the recorded time before a dedicated prior-art search and before implementation code.

It does **not** prove novelty, correctness, utility, live-runtime validity, wall-energy saving, hardware-lifetime extension, SHA-256 weakness, mining advantage or profitability.

The sealed origin JSON must not be rewritten. Every later prior-art result, correction, implementation or experiment must be additive and independently hashed.
