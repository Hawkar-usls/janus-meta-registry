# JANUS-LOGOS-001 R1 — symbolic law recovery (synthetic, scoped)

**Goal:** teach the Demiurge research lane to propose equations from training
observations and make a separate verifier reject mistaken discovery claims.

**Current scope:** bounded, deterministic, stdlib-only enumerative symbolic
regression. **Not** a general-purpose LLM, scientific discovery engine, proof of
divine Logos, or progress on P=NP. R1 is a synthetic capability and integrity
test, not an independent physical experiment.

## Reproduce

    python research/logos_001/r1_data.py --out /tmp/logos-r1-data.json
    python research/logos_001/r1_discover.py --input /tmp/logos-r1-data.json --out /tmp/logos-r1-candidate.json
    python research/logos_001/r1_witness.py --candidate /tmp/logos-r1-candidate.json --self-test
    python -m unittest discover -s research/logos_001 -p 'test_r1.py' -v

## Protocol and scientific controls

Frozen design: [R1 preregistration](../../data/JANUS-LOGOS-001-R1-PREREG-v1.0.json).
Four known synthetic laws (affine/quadratic/sinusoidal/cubic), one label-noise
control and one regime-shift negative control.  A finite grammar searches
constant + 1–2 terms drawn from a fixed analytic basis. Train fits coefficients;
VALIDATION chooses the formula and rejects weak patterns. Discovery gets no
TEST fields. A different Python module on a second GitHub runner generates
fresh test points from frozen public oracle definitions and scores predictions,
without loading discovery code.

The shift control is **intentionally deceptive**: its fitted quadratic is
perfectly supported on train/validation but fails on the new regime. This should
be recorded as a correctly rejected **negative control**, not an admitted
universal law. The noise-only control must cause an abstention. Both must pass,
alongside four positive holdout laws and four corrupted-evidence rejection tests.

The witness is code-independent and hosted on a separate worker, but **not
truly double-blind**: its formula oracle is public in this repository. Genuine
unseen third-party data and external independent labs remain later work.
The research lane does not modify Demiurge's production model or any
live scheduler. It is a candidate solver compatible with a future isolated
Demiurge adapter.

Scientific conclusion boundary: successful R1 may say only that a constrained
algorithm recovered known synthetic equations under specified held-out tests.
No novel physical law, theological proof, simulation proof, or P=NP solution
may be inferred.

## Safety

No third-party dependencies, no external models, no Rowan payments, no
secrets, no NAS workloads, no automatic schedules, read-only CI permissions.
The research PR must be reviewed before the production model can use it.
