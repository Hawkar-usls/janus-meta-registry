## New actual observed instruments

All original ASCII source files are mirrored exactly (Git blob SHA verified) from [Ceres Solver's NIST benchmark mirror](https://github.com/ceres-solver/ceres-solver/tree/master/data/nist), with direct NIST references:

- Hahn1 — 236 NIST observed copper thermal expansion readings: https://www.itl.nist.gov/div898/strd/nls/data/LINKS/DATA/Hahn1.dat
- Thurber — 37 NIST observed semiconductor electron mobility readings: https://www.itl.nist.gov/div898/strd/nls/data/LINKS/DATA/Thurber.dat
- Bennett5 — 154 NIST observed superconductivity magnetization readings: https://www.itl.nist.gov/div898/strd/nls/data/LINKS/DATA/Bennett5.dat

All repeated x values are kept in the same group. The discovery worker sees only TRAIN and VALIDATION measurements, whereas the independent verifier reconstructs the TEST set from source files and keeps it unavailable to the discoverer's input. NIST certified reference functional forms and source values are publicly known; **this is not a cryptographically blinded unknown-physics challenge**.

## Strong comparison

A separate witness runner fits and selects baselines from TRAIN/VALIDATION using pinned NumPy, SciPy and scikit-learn: OLS polynomial degrees 0–5, ridge polynomial, PCHIP interpolation, smoothing splines (three smoothing levels), random forest (three leaf sizes) and RBF kernel ridge (12 parameter settings). The strongest validation-selected baseline is evaluated on TEST without retuning.

A paired 2,000-repeat cluster bootstrap resamples independent TEST x-groups and reports a 95% percentile interval for relative RMSE gain over the selected baseline; this is a *conditional descriptive interval* for fixed trained models, not independent-lab evidence or guaranteed inference about all possible physical systems. Two population-level limitations are group correlation and potentially low holdout sample sizes.

The pre-frozen success condition requires all three tasks to produce a candidate with >5% TEST error reduction and CI lower bound >0. Three shuffled-validation-label negative controls must ABSTAIN. Four evidence tamper mutations must be rejected. All outputs must record their scientific competitiveness separately from protocol execution success.
