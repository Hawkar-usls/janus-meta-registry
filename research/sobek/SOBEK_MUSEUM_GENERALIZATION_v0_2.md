# JANUS Sobek museum generalization v0.2

This stage freezes a museum-scale Sobek target-candidate pool and a claim-safe blind-image follow-up protocol.

## Result ceiling

The current result is a **curator-description generalization screen**, not a blind image-morphology replication. Official museum descriptions already show Sobek in both relatively plain crocodile/crocodile-headed forms and in forms carrying elaborate solar/crown modules. That makes `CROCODILE_CORE + CONTEXTUAL_MODULES` a testable architectural hypothesis, but not yet an independently replicated visual law.

## Frozen gates

- Target-candidate pool: 36 records.
- Description-screened anchors: 27.
- Resolved broad period groups: EARLY, MIDDLE, NEW_KINGDOM, LATE_PTOLEMAIC, ROMAN.
- Staged ambiguity/control canaries: 7.
- Primary matched-control requirement remains open: >=20 non-Sobek crocodile controls and >=20 crown/solar non-Sobek controls.
- Blind image feature extraction remains `PREREGISTERED_NOT_EXECUTED`.

## Primary next test

Acquire and SHA-seal visually eligible museum images, anonymize them, freeze a period holdout, extract only predeclared crocodilian-core and crown/solar/context features while labels are hidden, freeze the feature table, then unblind. Promotion requires crocodilian core features to outperform crown-only/context-only features for Sobek identity while solar/crown features improve contextual discrimination inside Sobek, with matched controls and held-out-period replication.

## Wedjat comparison

The only permitted comparison at v0.2 is architectural: both projects test whether a stable visual identity core can combine with contextual modules. No direct Sobek-Wedjat lineage, fraction mapping, hidden text, or semantic equivalence is claimed.
